# MovieNight unRAID templates

Community Applications templates for the MovieNight three-container stack:

- `movienight.xml` — MovieNight application
- `movienight-transfer.xml` — MovieNight transfer engine
- `movienight-db.xml` — PostgreSQL database

## Community Applications installation

This repository is being prepared for Community Applications review. Its applications will appear in the Apps search after approval and a catalog update.

Once listed, open the Unraid Apps tab, search for MovieNight, and review the settings for all three containers before installing.

Unraid 6.10 and later no longer provide the old Template Repositories field. Repository publication is handled through the [Community Applications submission portal](https://ca.unraid.net/submit).

## Container images

- `ghcr.io/gorillaink/movienight:1.0.0`
- `ghcr.io/gorillaink/movienight-transfer:1.0.0`
- `postgres:17`
