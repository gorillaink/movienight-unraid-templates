# MovieNight unRAID templates

Community Applications templates for MovieNight.

Install in unRAID:
1. Settings -> Docker -> Template Repositories -> add:
   `https://github.com/gorillaink/movienight-unraid-templates`
2. Apps tab -> search MovieNight -> install all three containers.

Images are published to GHCR:
- `ghcr.io/gorillaink/movienight:1.0.0`
- `ghcr.io/gorillaink/movienight-transfer:1.0.0`
